# Example: skill-template

A real, complete run, so readers and agents can see what "working" looks like. If someone's run differs from this, that is what goes in the GitHub issue.

## Input

```text
/skill-template <what the user typed>
```

## What the agent did

The tool calls or commands it ran, in order, with anything it asked the user.

## Output

The final response, verbatim or lightly trimmed, plus any file or record it produced.

## Should not trigger on

One or two nearby requests this skill must ignore, so readers can check it is not firing too eagerly.
