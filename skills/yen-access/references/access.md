# Yen access reference

Use this reference for official access guidance; do not treat it as authorization to handle a user's credentials.

- Main documentation: https://rcpedia.stanford.edu/
- Access guide: https://rcpedia.stanford.edu/_getting_started/how_access_yens/
- JupyterHub guide: https://rcpedia.stanford.edu/_getting_started/jupyter/
- Cluster status: https://rcpedia.stanford.edu/status/

## Verified guidance

- Default access applies to GSB faculty, staff, PhD students, and research fellows. Other users need sponsored access from a GSB faculty member.
- SSH uses a SUNet ID, password, and Duo. The shared entry point is `yen.stanford.edu`.
- Interactive servers are `yen1` through `yen5`; use a full hostname for a specific server.
- JupyterHub is available independently at `https://yen1.stanford.edu` through `https://yen5.stanford.edu`. Users authenticate with SUNet credentials and start their own server.
- Recommend Stanford VPN for remote access issues. JupyterHub is not recommended in Safari.
